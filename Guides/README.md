# Technician Guides — Outline

These are planned procedures, not completed operating instructions. Each guide will identify the job, prerequisites, approved tool/button, expected result, restart implications, and when to escalate. The same task should be usable through the GUI or its documented BAT launcher.

| Planned guide | Scope |
| --- | --- |
| `00-Environment-Setup.md` | Obtain a reviewed release, choose configuration, verify runtime/dependencies, and locate reports. |
| `01-Prepare-and-Select-Management.md` | Identify the device and choose standalone provisioning or an approved identity/management workflow. |
| `02-Apply-Office-Baseline.md` | Select the office and department profile, install approved applications, and apply approved configuration. |
| `03-Validate-and-Handoff.md` | Run checks, resolve or document exceptions, and complete the assignment checklist. |
| `04-Updates-and-Maintenance.md` | Choose approved update/repair work, handle restarts, and review the post-maintenance report. |
| `05-Troubleshooting.md` | Use reviewed diagnostics and escalation guidance without changing unrelated settings. |
| `06-Windows-Upgrade-and-Migration.md` | Distinguish supported upgrades from older-system migration, backup, reimaging, and restoration. |
| `07-Device-Return-and-Removal.md` | Distinguish reassignment, reset, management retirement, record cleanup, and disposal. |

Standalone deployment must have a complete preparation-to-handoff path. AD, Entra, Intune, and Autopilot procedures are optional paths with their own prerequisites.

See the [current baseline](../Apps-Programs/workstation-environment.md), [checklist outlines](../Checklists/README.md), and [launchpad design](../Launchpad/README.md).
