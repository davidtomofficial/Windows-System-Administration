# Package Storage

This directory documents local package handling. The repository [.gitignore](../../.gitignore) excludes local payloads and subdirectories placed here while retaining this README.

Use official vendor distribution or approved internal package storage. Record source, publisher, version, architecture, signature validation, and file hash when acquiring a package. Confirm redistribution rights before including any vendor payload in a public release.

Large installation media, captured Windows images, license keys, private configuration, and device exports belong outside the public repository. Define their approved location through private environment configuration when deployment tooling is implemented.
