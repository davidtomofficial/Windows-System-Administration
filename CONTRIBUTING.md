# Contribution and review rules

Read [LICENSE.md](LICENSE.md) first. Request explicit permission before using or contributing covered original software outside an existing grant. Do not submit material whose ownership or license you cannot establish. Opening a discussion does not grant either party a broad license.

Use small reviewed changes, synthetic fixtures and exact source/test evidence. Keep historical attribution and task IDs. Do not commit real endpoint reports, credentials, tenant/customer data, vendor installers or private configuration. State whether work is implemented, tested, deployed or merely proposed.

Do not bypass execution policy, suppress tests to make CI green, change unrelated drafts, rewrite history, enable website hosting or run security labs as part of ordinary repository work. Use the [work-agent handoff](Docs/WORK-AGENT-HANDOFF.md) and [repository review TODO](Docs/REPOSITORY-REVIEW-TODO.md) for the approved scope.
