02 / Safe interactive example

Name planner / browser only

Generate fictional workstation labels without touching a real machine. All input and output remain on this page: no network calls, accounts, storage, or PowerShell execution.

  • Names: 1–15 ASCII characters with at least one letter
  • Letters, digits, and internal hyphens only
  • Validate the full selection; no partial output on errors
  • Maximum 256 synthetic targets

This demonstration is separately implemented in JavaScript; it is not evidence that the draft PowerShell module runs in your browser.
